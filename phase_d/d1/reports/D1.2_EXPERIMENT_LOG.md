## Experiment D1.2-E: Rank Transformations and Blending Protocols

- **Experiment ID:** `D1.2-E1` (Global Rank Mean), `D1.2-E2` (Within-Fold Rank Mean), `D1.2-E3` (Hybrid Blend)
- **Date/Time:** 2026-09-13T14:44:00+05:30
- **Parent Baseline:** D1.1 Baseline + D1.2-B Horizontal Flip
- **Purpose:** Investigate target-notebook-inspired rank transformations to resolve inter-fold calibration shifts and compare global percentile ranking vs within-fold percentile ranking.
- **Files Modified:** None.
- **Files Created:**
  - `phase_d/d1/scripts/d1_2_blend_experiments.py`: Blending and rank calibration engine.
  - `phase_d/d1/predictions/d1_2_e_blends/`: Blended prediction tables.
- **Files Untouched:** All D1.1 production checkpoints and baseline prediction artifacts.
- **Exact Parameter Changes:**
  - Arithmetic Probability Average: $P = 0.5 \cdot P_{\text{base}} + 0.5 \cdot P_{\text{flip}}$
  - Within-Fold Percentile Rank Normalization: $R_{i, c} = \frac{\text{rank}(P_{i, c})}{N_{\text{fold}}}$ evaluated per validation fold before concatenation.
  - Global Percentile Rank Normalization: $R_{i, c} = \frac{\text{rank}(P_{i, c})}{N_{\text{global}}}$.
- **Reason:** Model checkpoints across distinct CV folds exhibit minor intercept/baseline logit shifts. Within-fold rank calibration standardizes each fold's prediction distribution to a uniform $[0, 1]$ CDF before global aggregation.
- **Training Required:** No (Inference and post-processing only).
- **Global Unweighted Macro ROC-AUC:**
  - D1.1 Baseline alone with Within-Fold Rank Normalization: **`0.7576`** (Delta vs D1.1 raw: **`+0.0066`**)
  - Global Rank Mean (Base + Flip): `0.7518` (Delta vs D1.1 raw: `+0.0008`)
  - **Within-Fold Rank Mean (Base + Flip) [D1.2-E2 / D1.2-B2]:** **`0.7592`** (Delta vs D1.1 raw: **`+0.0082` / +1.09% relative gain**)
  - Hybrid Blend (50% Prob Mean + 50% Within-Fold Rank Mean): `0.7566` (Delta vs D1.1 raw: `+0.0056`)
- **Global Weighted Macro ROC-AUC:**
  - D1.1 Baseline with Within-Fold Rank: `0.7638` (Delta: `+0.0065`)
  - **Within-Fold Rank Mean (Base + Flip):** **`0.7658`** (Delta: **`+0.0085` / +1.12% relative gain**)
- **Global Macro PR-AUC:**
  - Within-Fold Rank Mean: **`0.2276`** (+0.0064 gain)
- **Integrity Audit:** 4,349 unique studies, 0 duplicates, 0 missing, 0 NaNs, 0 Infs, **0 Gold-58 contamination** (PASS).
- **Decision:** **KEEP (D1.2-E2 / D1.2-B2 Within-Fold Rank Mean is the WINNING PRODUCTION CANDIDATE).**
